# Math Quest — матэматычная віктарына

Дзіцячая онлайн-гульня па матэматыцы (на беларускай мове). Трэніруе табліцу множання і вусны лік.

## Як гуляць
1. Абяры тэму (напрыклад, табліцу множання).
2. Абяры рэжым.
3. Адказвай на прыклады і глядзі вынікі сесіі.

## Тэхналогіі
HTML + CSS + JavaScript (адна старонка `index.html`).

## Запуск
Статычны сайт — адкрый `index.html` або GitHub Pages.
